## Tim's technical update (Score architecture refactor)

A few weeks before the Apr 16 Spaces, the subnet went through a
major refactor:

- Challenges are no longer hard-coded in subnet software
- Validators now fetch a MANIFEST, a JSON file that encodes
  everything needed to run a competition: the challenge itself,
  emissions weight, scoring logic, model size constraints
- Score can now add new challenges at any point without a fresh
  deploy of subnet software
- Data sourcing is being scaled up, ground truth aligned with real
  client problems
- A fuel station detection challenge launched recently and produced
  strong models within a week

The manifest-driven architecture is the technical foundation that
lets Score serve multiple PwC enterprise verticals (retail,
manufacturing, logistics, energy, infrastructure) without code
changes for each new use case. It is the right architectural
choice for the go-to-market they have described.
