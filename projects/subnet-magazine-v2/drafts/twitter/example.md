This file is NOT in `ready/` — it's a format example only. Real drafts
go in `ready/` with a filename like:

    2026-05-29_1430Z--affine-7pct-1y.md

The filename's UTC timestamp is when the Action will post it. The body
below is what gets tweeted verbatim (stripped of leading/trailing
whitespace).

---
